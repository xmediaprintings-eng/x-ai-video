# Music library

Put background music files here (`.mp3`, `.m4a`, `.wav`). The AI sees the file names and
picks one that fits, so name them by mood, for example:

- `soft-piano-calm.mp3`
- `upbeat-pop-energetic.mp3`
- `cinematic-reveal.mp3`

Only use music you have the rights to (royalty-free / licensed). Facebook and TikTok may
mute videos that use copyrighted songs.
