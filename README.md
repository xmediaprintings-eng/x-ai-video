# X Media AI Video — ตัดต่อวิดีโอด้วย AI 100%

อัปโหลดคลิป/รูป → พิมพ์ว่าอยากได้วิดีโอแบบไหน → AI ตัดต่อให้เสร็จ → ได้ไฟล์ **MP4** พร้อมโพสต์

## ทำอะไรได้บ้าง (เวอร์ชัน 0.1)

| ขั้นตอน | AI / โปรแกรมทำอะไร |
|---|---|
| **ดูคลิป** | แยกฉากอัตโนมัติ ดึงภาพจากทุกฉากให้ Claude ดูว่าแต่ละช่วงมีอะไร |
| **ฟังเสียง** | ถอดเสียงพูดเป็นข้อความพร้อมเวลา (Whisper) ใช้ทำซับไตเติล |
| **วางแผนตัดต่อ** | Claude เลือกช็อต ลำดับ ความยาว ความเร็ว transition ตัวหนังสือ เพลง |
| **Render** | FFmpeg ตัดต่อเป็น MP4 ขนาด 9:16 / 4:5 / 1:1 / 16:9 พร้อมโลโก้ เพลง (ลดเสียงเพลงอัตโนมัติตอนมีคนพูด) และฉากปิดท้ายที่มีชื่อร้าน + เบอร์โทร |
| **แก้ด้วยการแชท** | พิมพ์ เช่น "ตัดช่วงต้นให้สั้นลง ตัวหนังสือใหญ่ขึ้น" → AI แก้แผน → render เวอร์ชันใหม่ (เก็บทุกเวอร์ชัน) |

- ตัวหนังสือ **ลาว / ไทย / อังกฤษ** แสดงถูกต้อง (ฟอนต์ Noto รวมไว้ในโปรแกรมแล้ว)
- ใช้จาก**มือถือ**ได้ (เปิดผ่าน Wi-Fi เดียวกับคอมพิวเตอร์)
- ไม่มี API key ก็ลองใช้ได้ (โหมดทดลอง: ตัดตามฉากอัตโนมัติ ไม่ได้ใช้ AI)

## ติดตั้งบน Windows

1. ดาวน์โหลดโปรเจกต์: บนหน้า GitHub กด **Code → Download ZIP** แล้วแตกไฟล์ (หรือ `git clone`)
2. ดับเบิลคลิก **`start.bat`**
   - ถ้ายังไม่มี Python หรือ FFmpeg โปรแกรมจะติดตั้งให้ผ่าน winget → **ปิดหน้าต่างแล้วดับเบิลคลิก `start.bat` อีกครั้ง**
   - ครั้งแรกจะติดตั้งแพ็กเกจอยู่สักครู่
3. เบราว์เซอร์จะเปิด `http://localhost:8000` ให้อัตโนมัติ
4. กด **⚙** → ใส่ **Claude API key** → บันทึก (ใส่ชื่อร้าน เบอร์โทร และโลโก้ PNG ได้ที่หน้านี้)

### ขอ Claude API key
1. เข้า [console.anthropic.com](https://console.anthropic.com) → สมัคร/เข้าสู่ระบบ
2. เติมเครดิต (Billing) → ไปที่ **API Keys** → **Create Key**
3. คัดลอก key (ขึ้นต้นด้วย `sk-ant-`) มาวางในหน้า ⚙ ของโปรแกรม

ค่าใช้จ่ายโดยประมาณ: ใช้ Sonnet 5.5 (ราคา $2 / $10 ต่อล้าน token) ตกประมาณ **0.05–0.10 USD ต่อการตัดต่อ 1 ครั้ง** (ขึ้นกับจำนวนคลิปและรูป) ส่วน FFmpeg และ Whisper ฟรี เพราะทำงานบนเครื่องของคุณ

### ใช้จากมือถือ
- มือถือกับคอมพิวเตอร์ต้องต่อ **Wi-Fi เดียวกัน**
- ดูที่อยู่ในหน้าต่างดำ เช่น `On your phone : http://192.168.1.25:8000` แล้วพิมพ์ในเบราว์เซอร์มือถือ
- ถ้า Windows ถามเรื่อง Firewall ให้กด **Allow** (Private network)

## วิธีใช้
1. แตะ **＋** เลือกวิดีโอ/รูปได้หลายไฟล์
2. พิมพ์คำสั่ง เช่น *"ໂຄສະນາກ່ອງໄຟ 20 ວິ ສຳລັບ Reels — ເປີດດ້ວຍຊອດປ້າຍໄຟສວຍທີ່ສຸດ"*
3. เลือกขนาด ความยาว เปิด/ปิดซับไตเติล และใส่เพลงได้ถ้าต้องการ
4. กด **✨ ສ້າງວິດີໂອດ້ວຍ AI** → รอ → ดาวน์โหลด MP4
5. ถ้ายังไม่ถูกใจ ให้พิมพ์สิ่งที่อยากแก้ในช่อง **ແກ້ໄຂດ້ວຍການພິມ** หรือเปิด **JSON** เพื่อแก้เองแบบละเอียด

**เพลง:** วางไฟล์ mp3 ไว้ใน `assets/music/` (ตั้งชื่อไฟล์ตามอารมณ์เพลง AI จะเลือกให้) หรืออัปโหลดตอนสร้างงาน ควรใช้เพลงที่มีลิขสิทธิ์ถูกต้อง เพราะ Facebook/TikTok อาจปิดเสียงวิดีโอที่ใช้เพลงติดลิขสิทธิ์

## ข้อจำกัดที่ควรรู้
- **ซับไตเติลภาษาลาว:** Whisper ถอดเสียงลาวได้ แต่ยังแม่นยำไม่มาก (ภาษาไทยแม่นกว่า) ควรดูก่อนโพสต์ แก้คำผิดได้ใน JSON
- เอฟเฟกต์ซูมแบบลื่นใช้ได้กับ**รูป** ส่วนวิดีโอใช้ซูมแบบ crop (punch-in)
- Render ใช้ CPU: คลิป 30 วินาทีที่ 1080p ใช้เวลาประมาณ 1–3 นาที ขึ้นกับเครื่อง (เลือก 720p จะเร็วขึ้น)

## โครงสร้างโปรเจกต์
```
app/
  main.py        API server (FastAPI)
  jobs.py        คิวงาน: วิเคราะห์ → AI วางแผน → render
  media.py       FFmpeg probe, แยกฉาก, ดึงภาพ, ถอดเสียง (faster-whisper)
  planner.py     prompt + tool schema ของ Claude, แผนสำรอง, ตรวจสอบแผน
  render.py      ตัดต่อด้วย FFmpeg (xfade, ซับไตเติล ASS, โลโก้, เพลง, loudnorm)
  textlayout.py  จัดตัวหนังสือลาว/ไทย ตัดบรรทัด ซับไตเติล ฉากปิดท้าย
  static/        หน้าเว็บ (ใช้บนมือถือได้)
assets/fonts/    XMedia Sans = Noto Sans + Noto Sans Lao + Noto Sans Thai (SIL OFL)
tests/           smoke_test.py (ทดสอบ render ครบวงจร), test_planner_mock.py
```
ทดสอบ: `python -m tests.smoke_test` และ `python -m tests.test_planner_mock`
